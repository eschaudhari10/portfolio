# Eesha Chaudhari — Portfolio

Single-page static site. Open `index.html` in a browser; no build step.

- `index.html`: page, styles and scripts (GSAP + ScrollTrigger and Lenis load from CDNs; the page still renders without them).
- `assets/`: source SVG illustrations for each project and the hackathon award. They are embedded in `index.html` as base64 data URIs, so after editing one, re-embed it.
- `resume/Eeshacv .pdf`: linked from the "Résumé" buttons.

Deploy by uploading the folder to any static host (Vercel, Netlify, GitHub Pages).
